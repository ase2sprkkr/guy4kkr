# XBand structure database

`ITXC_structure.dat` is copied from XBand 8.6 (November 2021), by H. Ebert,
University of Munich. XBand describes itself as free under the GNU license
conditions.

Guy4ASE reads the original file format directly. The data defines structure
prototypes: space-group settings and occupied Wyckoff sites. It does not
contain lattice parameters, element assignments, or numeric values for
symbolic `x`, `y`, and `z` coordinates.
